# 3-minute hackathon demo

1. Introduce the problem: recruiters receive many resumes and need a transparent way to compare relevant skills.
2. Paste the sample Software Engineer Intern job description.
3. Upload several synthetic demo resumes in PDF, DOCX, or TXT format.
4. Click **Analyze candidates**.
5. Explain the ranking, matched keywords, and missing keywords.
6. Explain limitations: this is a prototype based on keyword overlap, not a validated hiring model. Human review is mandatory.

## Suggested future improvements
- Semantic matching using sentence embeddings
- Role-specific skill taxonomy and configurable weighting
- Recruiter accounts and access controls
- Audit logs, consent, retention controls, and secure storage
- Evaluation against a labeled, representative dataset
